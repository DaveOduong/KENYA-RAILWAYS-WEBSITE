# KENYA RAILWAYS WEBSITE

## 1. Project Overview

The Kenya Railways Website is a simple web-based project developed using HTML5 and CSS3. The website is designed to provide users with basic information about railway transportation in Kenya.

It provides a central place where visitors can explore available railway routes, view sample train schedules, check indicative fares, and access contact information.

The project demonstrates the use of HTML to structure website content and CSS to control its appearance, layout, and responsiveness.

## 2. Project Objectives

The main objectives of this project are:

- To develop a simple and user-friendly railway information website.
- To display train schedules in an organized table.
- To present different railway routes and their sample fares.
- To provide visitors with accessible contact information.
- To demonstrate practical application of HTML5 and CSS3 concepts.
- To create a website with simple navigation between different sections.

## 3. Website Features

### A. Header and Navigation

The header appears at the top of the website and contains the Kenya Railways title and tagline.

It also contains a navigation menu with four links:

- Home – Takes users to the welcome section.
- Schedule – Directs users to the train timetable.
- Routes – Displays available railway routes.
- Contact – Takes users to the contact information in the footer.

The navigation uses HTML anchor links to move between sections without opening separate pages.

### B. Welcome Section

This section introduces visitors to the website.

It contains a welcome heading, a short description of the services provided by the website, and a button labelled "View Schedule".

The button directs visitors to the train schedule section, making navigation easier.

### C. Train Schedule Section

This section displays a sample railway timetable using an HTML table.

The table contains the following information:

- Train – Identifies the train service.
- From – Shows the departure station.
- To – Shows the destination station.
- Departure – Displays the scheduled departure time.
- Arrival – Displays the expected arrival time.
- Fare (KES) – Shows the sample ticket price in Kenyan Shillings.

The table is organized using table headings, rows, and data cells to make information easy to read.

### D. Our Routes Section

This section presents six sample railway routes in separate cards.

Each route card contains:
- The route name.
- A short description of the journey.
- An indicative starting fare.

The routes displayed include Nairobi–Mombasa, Nairobi–Naivasha, Nairobi–Syokimau, Nairobi–Ruiru, Mombasa–Voi, and Nairobi–Athi River.

This section uses HTML article elements and CSS classes to organize the route information.

### E. Contact and Footer Section

The footer appears at the bottom of the website and contains important information.

It is divided into two main areas:

**Contact Us**
- Telephone number.
- Email address.
- Physical address.

**Quick Links**
- Schedule.
- Routes.
- Back to top.

A copyright notice is also included to identify the website and its year.

## 4. Technologies Used

### HTML5
HTML5 is used to create the structure and content of the website.

Some of the HTML elements used include:

- `<header>` – Defines the top section of the website.
- `<nav>` – Contains the navigation menu.
- `<main>` – Holds the main website content.
- `<section>` – Separates content into different sections.
- `<article>` – Groups individual railway route cards.
- `<table>` – Displays train schedules.
- `<footer>` – Contains contact information and copyright details.
- `<a>` – Creates navigation links.

### CSS3
CSS3 is used through an external stylesheet named `style.css`.

It is responsible for the visual presentation of the website, including colours, fonts, spacing, borders, navigation styling, route cards, and page layout.

## 5. Project Structure

The project contains three main files:

```text
Kenya-Railways/
│
├── index.html
├── style.css
└── README.md
```

- **index.html:** Contains the website structure, text, navigation, timetable, route information, and footer.
- **style.css:** Contains the styling rules that determine how the website looks.
- **README.md:** Provides documentation explaining the project, its features, and instructions for running it.

## 6. How to Run the Project

Follow these steps to open the website:

1. Download or copy the project files into a folder.
2. Ensure that `index.html` and `style.css` are saved in the same directory.
3. Open the project folder.
4. Double-click `index.html` to open it in a web browser.
5. Use the navigation menu to explore the different website sections.

No additional software or database is required to view the website.

## 7. HTML Concepts Demonstrated

The project demonstrates several important HTML concepts:

- **Semantic HTML:** Using meaningful elements such as header, main, section, article, and footer.
- **Classes:** Using the `class` attribute to group elements for CSS styling.
- **IDs:** Using unique identifiers to target specific sections and create internal navigation.
- **Hyperlinks:** Using anchor elements to connect different sections.
- **HTML Tables:** Organizing train schedules into rows and columns.
- **External CSS:** Connecting an external stylesheet using the `<link>` element.
- **Document Structure:** Using HTML elements such as head, body, headings, paragraphs, and lists.

## 8. Limitations

- The train schedules and fares are sample information and are not verified official railway data.
- The website does not provide actual ticket booking.
- It does not connect to a railway database.
- Contact details are demonstration placeholders.
- Train schedules and fares are not updated automatically.

## 9. Future Improvements

The website can be improved by introducing:

- An online ticket booking system.
- A search feature for railway routes.
- Real-time train schedules.
- Online payment integration.
- A database for storing train and passenger information.
- A dedicated mobile-friendly booking interface.

## 10. Conclusion

The Kenya Railways Website demonstrates how HTML5 and CSS3 can be used to develop a simple and organized railway information platform.

It provides visitors with an easy way to explore sample train schedules, railway routes, fares, and contact information.

The project also provides practical experience in website development, semantic HTML, page organization, navigation, and external CSS styling.
